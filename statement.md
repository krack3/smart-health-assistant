# Problem Statement
Maintaining a healthy lifestyle can be challenging for students and professionals, especially without consistent monitoring of daily habits. Many lack tools for quick, personalized feedback about their activity, hydration, and sleep. This project aims to provide a simple yet effective solution to help individuals track their basic health data, receive feedback, and build better habits using a user-friendly Python application.

# Scope of the Project

- Collect key daily health inputs (age, weight, height, steps, water intake, sleep duration) from the user.
- Analyze and report essential health metrics: BMI calculation and categorization, suggested water intake, step and sleep feedback.
- Present users with clear, actionable feedback for each health parameter.
- Operate as a console application for maximum accessibility.
- Designed to be modular and extensible for additional health features/goals in future versions.

# Target Users

- Students, professionals, and anyone interested in monitoring daily health.
- Beginners in fitness who want a fast, simple tool for daily health insights.
- Individuals who prefer lightweight, console-based solutions over complex apps.

# High-level Features

- User-friendly prompts: Intuitive questions for health data entry.
- BMI calculation and categorization:  Computes BMI from weight and height and displays health category (Underweight, Normal, Overweight, Obese).
- Water intake goal: Suggests daily water intake based on user's weight.
- Physical activity feedback: Provides feedback based on the number of steps walked.
- Sleep analysis: Reviews sleep hours and delivers guidance.
- Clear health summary report: Presents all data and suggestions in a concise summary.
- Modular design: Each core function separated for maintainability and future growth.
