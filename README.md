# Smart Health Assistant

## Overview
Smart Health Assistant is a simple Python console application that helps users monitor their daily health habits. By entering basic details like age, weight, height, steps, water intake, and sleep hours, the assistant calculates BMI, gives feedback on physical activity and sleep, and suggests your daily water intake goal.

## Features
- Input prompts for basic health details
- BMI calculation and categorization
- Water intake goal suggestion based on weight
- Personalized feedback on daily steps walked
- Sleep duration analysis and feedback
- Clean summary output of your health data

## Technologies/Tools Used
- Python 3 (core language)
- Standard Python modules only (no external libraries required)
